# Khush Patel - Personal Portfolio

A responsive portfolio website created with HTML5, CSS3 and JavaScript.

## Files
- `index.html` - semantic page structure and accessible form/navigation
- `style.css` - responsive design, CSS animations, cards and dark mode styling
- `script.js` - mobile navigation, dark mode, form validation and scroll animations

## Run locally
Open `index.html` in a web browser.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all three website files.
3. Go to Settings -> Pages.
4. Select the main branch and root folder.
5. Save and copy the generated GitHub Pages URL.
